# Installation

## 1. Clone Project

```bash
git clone https://github.com/YOUR_USERNAME/bhagyraj-tea.git
```

---

## 2. Open Project

```bash
cd bhagyraj-tea
```

---

## 3. Install Dependencies

```bash
composer install
```

```bash
npm install
```

---

## 4. Create Environment File

```bash
copy .env.example .env
```

---

## 5. Generate App Key

```bash
php artisan key:generate
```

---

## 6. Configure Database

Open `.env`

Update:

```env
DB_DATABASE=bhagyraj_tea
DB_USERNAME=root
DB_PASSWORD=
```

---

## 7. Run Migration

```bash
php artisan migrate
```

---

## 8. Start Vite

```bash
npm run dev
```

---

## 9. Start Laravel Server

```bash
php artisan serve
```
